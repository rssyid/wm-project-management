# 05 — UI Flow dan Design System

Status: disetujui 10 Oktober 2026. Bahasa UI Indonesia. Desain dicoba pemilik proyek dengan tiga akun role sebelum implementasi UI (F0).

## 1. Prinsip

- Tampilkan hanya aksi yang boleh untuk role dan status; aksi yang belum memenuhi syarat tampil nonaktif dengan alasan.
- Tombol menyebut akibatnya ("Terbitkan USPK", "Release SPK", "Catat Kiriman"), bukan "Simpan".
- Status proyek dan status proses selalu label terpisah.
- Approval selalu diberi keterangan "keputusan di SAP, dicatat oleh user".
- Setiap pembatalan memakai dialog sendiri dengan alasan wajib.
- Riwayat (attempt batal, SPK batal, revisi, log digantikan) tidak pernah disembunyikan, termasuk di mobile.
- Viewer melihat layar yang sama tanpa tombol aksi.

## 2. Design system

Nilai token, layout shell, pola halaman, dan larangan visual yang mengikat ada di `.kilo/rules/35-design.md`. Ringkasan:

- Komponen shadcn/ui (Tailwind v4, gaya new-york, token OKLCH), ikon lucide-react, toast sonner.
- Mode terang saja. Warna utama biru tua; netral abu-abu.
- Warna semantik tetap: EWS hijau/kuning/merah; Gantt baseline abu-abu, revisi pertama kuning, revisi berikutnya oranye, plus pola garis pada sel revisi.
- Font Inter dengan cadangan system font. Tabel desktop padat (compact).
- Format: tanggal `10 Okt 2026`, uang `Rp1.250.000.000`, persen `65,4%`.
- Kontras WCAG AA, fokus terlihat, navigasi keyboard, `aria-label` untuk ikon dan sel Gantt.

## 4. Alur utama

Buat proyek → Survei → AFCE dan BOQ → Ajukan (+ tanggal email) → Catat keputusan SAP per level (ditolak → attempt AFCE baru) → Pekerjaan + bobot → cabang per Pekerjaan:

- Tender: Terbitkan USPK + plan → Mulai Tender → Catat pemenang → Release SPK → Mulai Pekerjaan Fisik.
- Swakelola: SPK vendor internal → Release SPK → Mulai Pekerjaan Fisik; material lewat Paket Kerja.
- Pembelian: Terbitkan PR → Catat PO → Produksi (opsional) → Catat Kiriman.

→ Pelaksanaan (log progres mingguan + kiriman) → Ajukan BAST (fisik 100%) → Verifikasi (SA) → selesai, read-only. Tahan/Batal tersedia dari menu "Lainnya".

## 5. Dashboard, daftar, portofolio, laporan

Bar filter bersama: ops, Region, Wilayah, Company (multi), kategori, status, EWS, kata kunci; filter terakhir disimpan di browser.

- Dashboard: kartu jumlah per status; jumlah EWS merah/kuning; progres berbobot rata-rata; 10 proses dengan deviasi terbesar; Kurva S portofolio; daftar Pekerjaan yang belum punya log minggu ini.
- Daftar proyek: kode, nama, kategori, Company, Estate utama (+N), status, progres, EWS, PIC, target selesai; tombol "Buat Proyek"; toggle arsip. Mobile: kartu.
- Portofolio: Gantt matriks proyek terfilter; ekspor.
- Laporan: pilih laporan → filter → pratinjau → "Unduh Excel" / "Unduh PDF".

## 6. Workspace proyek

Header: kode, nama, kategori, badge status, Company, Estate, Wilayah/Region, PIC, target, anggaran (rencana sebelum AFCE Approved, resmi sesudahnya), progres, EWS. Banner kuning saat ditahan; abu-abu saat selesai/batal/arsip.

Panel "Langkah berikutnya" (1–3 aksi + prasyarat yang belum terpenuhi):

| Status | Aksi utama |
| --- | --- |
| DRAFT | Lengkapi data dasar → Mulai Survei |
| SURVEY | Isi survei → Buat AFCE → isi BOQ → tandai RAB siap |
| RAB_READY | Periksa level → Ajukan AFCE |
| WAITING_AFCE_AR | Catat keputusan {jabatan} |
| AFCE_AR_APPROVED | Tambah Pekerjaan & bobot → Terbitkan USPK / Buat SPK swakelola / Terbitkan PR |
| PROCUREMENT | Mulai Tender, Catat Pemenang, Release SPK, Mulai Pekerjaan Fisik; Catat PO, Produksi, Kiriman |
| EXECUTION | Isi Log Progres Minggu Ini; Catat Kiriman; Ajukan BAST (saat fisik 100%) |
| WAITING_BAST | Verifikasi BAST / Batalkan Pengajuan BAST (SA) |
| ON_HOLD | Lanjutkan Proyek |
| COMPLETED, CANCELLED | Hanya ekspor |

Tab: Ringkasan · Survei · AFCE/AR · Pekerjaan (detail: attempt & USPK, SPK, fisik & log, Paket pendukung) · Paket Kerja · Jadwal (Gantt) · BAST · Riwayat.

## 10. Master dan admin

Pola sama: tabel + cari + filter aktif, panel ubah di samping, "Nonaktifkan" untuk data terpakai. Lokasi: pohon Region → Wilayah → Estate (Company kolom), Block di detail Estate. Vendor/Material: filter "Belum lengkap". Jabatan: urutan bisa digeser. Matriks approval (SA): editor tier + level, peringatan tumpang tindih/berlubang, teks bantuan batas. User (SA). Hari kerja & libur (SA). Ambang EWS (SA) dengan pratinjau. Proyek terhapus (SA): Pulihkan / Purge (ketik kode). Audit log: filter + before/after.
